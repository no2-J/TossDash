# TossDash
토스 주식 현황을 볼 수 있는 Dashboard 프로그램

### 🚀 시작하기
1. 이 리포지토리를 클론하거나 다운로드합니다.
2. 필요한 라이브러리를 설치합니다:
   ```bash
   pip install -r requirements.txt
   ```
3. 프로그램을 실행합니다:
   ```bash
   python main.py
   ```
    
💡 설정 정보 수정이 필요할 때
언제든 설정을 다시 바꾸고 싶으시다면, 터미널(CMD) 창에서 아래 명령어를 입력하여 설정 창을 다시 띄울 수 있습니다.
Bash

python main.py --setup

⚠️ 필수 보안 주의사항

- 이 프로그램은 개인 학습 목적으로 만들어졌으며, 사용에 따른 책임은 사용자 본인에게 있습니다. 

-프로그램 실행 시 생성되는 config.json 파일에는 사용자의 API 접근 정보가 포함되어 있습니다. 절대로 타인과 공유하거나 인터넷에 올리지 마십시오.

-requirements.txt와 소스 코드는 자유롭게 배포하셔도 좋으나, 개인 설정 파일은 항상 본인의 컴퓨터 내에서만 관리해 주시기 바랍니다.

-이 프로그램은 인터넷 유출은 차단되어있지만, 사용자 PC 내부에서의 보안은 취약합니다. (config.json 평문 노출) API Key와 Secret Key가 암호화되지 않은 텍스트로 저장되어 있으니 이 프로그램을 공용 PC나 회사 PC에 사용하실 때 주의하십시오.

-토스 API 서버에서 보내주는 데이터 구조에 프로그램이 강하게 결합되어 있습니다. 토스 측에서 API 응답구조나 키워드를 하나라도 변경하면 프로그램에서 자산을 0원으로 표시하는 오류가 생길 수 있으니, 이 프로그램을 너무 신용하지 말아주시기 바랍니다.

-또한 알 수 없는 이유로 실제 자산과 프로그램에서 표시하는 자산의 값이 조금 맞지 않습니다. 유의해주시기 바랍니다.
