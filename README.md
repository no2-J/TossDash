# TossDash
토스 주식 현황을 볼 수 있는 Dashboard 프로그램

설치 및 실행 방법
방법 1: Git 사용자 (터미널 사용)

이미 Git이 설치되어 있고 개발 환경에 익숙한 경우, 아래 명령어를 사용하여 간편하게 설치할 수 있습니다.

    리포지토리를 클론합니다:
    git clone https://github.com/본인아이디/TossTick.git
    cd TossTick

    필수 라이브러리를 설치합니다:
    Bash

    pip install -r requirements.txt

    프로그램을 실행합니다

방법 2: 일반 사용자 (Git 설치 불필요)

Git을 사용하지 않으시거나 터미널 사용이 낯선 경우, 웹 브라우저만으로도 간단히 실행할 수 있습니다.

    파일 다운로드: 리포지토리 상단의 [Code] 버튼을 누르고 [Download ZIP]을 선택하여 압축 파일을 다운로드합니다.

    압축 해제: 다운로드한 파일을 원하는 폴더에 압축을 풉니다.

    라이브러리 설치:

        윈도우 검색창에 cmd를 입력하여 명령 프롬프트를 엽니다.

        cd 명령어를 입력하고 한 칸 띄운 뒤, 압축을 푼 폴더 경로를 드래그해서 넣고 엔터를 누릅니다. (예: cd C:\Users\Downloads\TossTick-main)

        아래 명령어를 입력하여 필요한 도구들을 설치합니다:

        pip install -r requirements.txt

    프로그램 실행
    
💡 설정 정보 수정이 필요할 때
언제든 설정을 다시 바꾸고 싶으시다면, 터미널(CMD) 창에서 아래 명령어를 입력하여 설정 창을 다시 띄울 수 있습니다.
Bash

python main.py --setup

⚠️ 필수 보안 주의사항

    프로그램 실행 시 생성되는 config.json 파일에는 귀하의 소중한 API 접근 정보가 포함되어 있습니다. 절대로 타인과 공유하거나 인터넷에 올리지 마십시오.

    requirements.txt와 소스 코드는 자유롭게 배포하셔도 좋으나, 개인 설정 파일은 항상 본인의 컴퓨터 내에서만 관리해 주시기 바랍니다.
