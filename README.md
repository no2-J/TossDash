# TossDash
토스 주식 현황을 볼 수 있는 Dashboard 프로그램

### 🚀 시작하기
1. 이 리포지토리를 클론하거나 다운로드합니다.
2. 필요한 라이브러리를 설치합니다:
   ```bash
   pip install -r requirements.txt
   ```
3. 프로그램을 실행합니다:
   ```bash
   python main.py
   ```
    
💡 설정 정보 수정이 필요할 때
언제든 설정을 다시 바꾸고 싶으시다면, 터미널(CMD) 창에서 아래 명령어를 입력하여 설정 창을 다시 띄울 수 있습니다.
Bash

python main.py --setup

⚠️ 필수 보안 주의사항

    프로그램 실행 시 생성되는 config.json 파일에는 귀하의 소중한 API 접근 정보가 포함되어 있습니다. 절대로 타인과 공유하거나 인터넷에 올리지 마십시오.

    requirements.txt와 소스 코드는 자유롭게 배포하셔도 좋으나, 개인 설정 파일은 항상 본인의 컴퓨터 내에서만 관리해 주시기 바랍니다.
